Library Management System

Koha is an open-source integrated library system (ILS), used worldwide by public, school and special libraries, as well as larger academic libraries. Koha is a fully featured, scalable library management system developed and supported by libraries globally.

Request a Demo Contact Us

Comprehensive Library Management


Koha is a web-based ILS with a SQL database (MariaDB or MySQL) back end, with cataloguing data stored in MARC and accessible via Z39.50 or SRU. The user interface (OPAC) is configurable and has been translated into many languages. Development is sponsored by libraries of varying types and sizes, volunteers, and support companies worldwide.

Integrated Modules


  • Union catalog facility
  • Online circulation
  • Barcode printing
  • Patron card creation
  • Report generation
  • Patron self-registration via OPAC
  • Cataloguing
  • Circulation
  • Serials
  • Acquisition
  • Administration
  • Integration with discovery

Key Highlights


Full-Featured ILS

Comprehensive functionality including acquisitions, circulation, cataloguing, serials management, and flexible reporting.

Multilingual & Translatable

Support for large number of available languages with more added every year for global accessibility.

Standards Compliant

Built using library standards including MARC 21, Z39.50, SIP2, and NCIP for seamless interoperability.
