Library Management System

Koha is an open-source integrated library system (ILS) used worldwide by public, school and special libraries, as well as larger academic libraries. A fully featured, scalable library management system with a configurable web-based OPAC translated into many languages.

Request a Demo Contact Us

A World-Class Open-Source ILS


Koha is a web-based ILS with a SQL database (MariaDB or MySQL) back end, with cataloguing data stored in MARC and accessible via Z39.50 or SRU. Development is sponsored by libraries of varying types and sizes, volunteers, and support companies worldwide. The user interface (OPAC) is configurable and has been translated into many languages.

Koha Modules


  • Union catalog facility
  • Online circulation
  • Barcode printing
  • Patron card creation
  • Report generation
  • Patron self-registration via OPAC
  • Cataloguing
  • Circulation
  • Serials
  • Acquisition
  • Administration
  • Integration with discovery

Key Highlights


Full-Featured ILS

Comprehensive functionality including acquisitions, circulation, cataloguing, serials, flexible reporting, and offline circulation — works for consortia, multi-branch, and single-branch libraries.

Library Standards Compliant

Built using MARC 21, UNIMARC, Z39.50, SRU/SW, SIP2 and SIP/NCIP — ensuring full interoperability with other systems and technologies.

Full-Text Search

Powerful searching with enhanced catalogue display integrating content from Amazon, Google, LibraryThing, Open Library, and Syndetics.
