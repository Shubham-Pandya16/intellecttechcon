CAD Software

CAD software used to increase the productivity of the designer, improve the quality of design and to create a database for architectural, engineering and construction applications. Built on the latest IntelliCAD 10.1 Engine with full AutoCAD file format compatibility.

Request a Demo Contact Us

Professional CAD for Every Discipline


By using the latest IntelliCAD 10.1 Engine, Open Design Alliance, dwg/dxf Libraries, ACIS 3D Modelling Kernel, and many other technologies, it ensures file support from early R2.5 right through to the latest version of dwg/dxf. It also supports other file formats including .dgn, .step/.stp, .iges/.igs, .stl, .obj, 2D PDF, 3D PDF, .svg, and .dae. The interface and commands are designed to be familiar and easy to migrate from any CAD software.

Key Features


  • Access Tutorial Videos from within the software
  • Block Library of over 5,000 Blocks (user can add custom blocks too)
  • ActCAD Converter: Batch Auditing and File Conversions
  • Convert PDF to DWG/DXF Files from within the software
  • Artisan 3D Renderer – Create Photorealistic Presentations/Drawings
  • Option for permanent licence
  • Fully compatible with AutoCAD file formats
  • Convert Image to DWG/DXF Files – Raster to Vector
  • Simple Self-Help Module to address common queries

Key Capabilities


3D Photorealistic Rendering

Artisan 3D Renderer creates photorealistic presentations and drawings to bring designs to life before construction.

Universal File Compatibility

Supports DWG/DXF from R2.5 to latest versions, plus .dgn, .step, .iges, .stl, .obj, PDF and more.

5,000+ Block Library

A comprehensive built-in block library with over 5,000 items, fully extensible with your own custom blocks.
